# MovieBox Mini App V2

- Added a dedicated Downloads tab.
- Added direct authorized media URL downloads.
- Added transfer progress where the server exposes Content-Length and permits CORS.
- Added browser download handoff (typically Android Downloads folder).
- Added download history, re-download, and remove controls.
- Retained the V1 movie discovery, favorites, history, IPTV playlist import, and player foundation.

Limitations: no pause/resume, DRM bypass, scraping, protected stream extraction, or guaranteed background download. Browser and source CORS/format restrictions apply.
